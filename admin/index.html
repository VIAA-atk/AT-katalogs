VIAA Asistīvo tehnoloģiju kataloga administrēšana Publiskais katalogs

Savienojums ar GitHub

Administrēšanas lapa ir publiski atverama, taču ierakstus var mainīt tikai lietotājs ar rakstīšanas tiesībām repozitorijā VIAA-atk/AT-katalogs.

Izmanto fine-grained tokenu, kas piešķirts tikai šim repozitorijam ar atļauju Contents: Read and write. Tokens tiek turēts tikai šīs cilnes atmiņā un pēc pārlādes pazūd.

Kā droši izveidot tokenu
  1. GitHub atver Fine-grained personal access token.
  2. Pie “Repository access” izvēlies tikai AT-katalogs.
  3. Pie “Repository permissions” iestati Contents — Read and write.
  4. Izvēlies īsu derīguma termiņu. Nekopīgo tokenu un neievieto to failos.
